# 🌤️ Zalik Weather App

Мобільний додаток для перегляду погоди, розроблений на React Native з Expo.

## Функціонал
- 🔍 Пошук міста з автодоповненням
- 🌡️ Поточна температура
- 🌤️ Іконка та опис погоди
- 💧 Вологість
- 💨 Швидкість вітру
- 👁️ Видимість та тиск
- 🎨 Динамічний градієнт фону

## Технології
- React Native
- Expo SDK 54
- OpenWeatherMap API

## Запуск
1. Встановити залежності: `npm install`
2. Запустити: `npx expo start`
3. Відсканувати QR-код через Expo Go
